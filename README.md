# Karonga Village Bank — Bank Mmuzi

**By:** Nehemiah Ng'anjo
**Language:** Python

## what is this

a village banking system for bank mmuzi in karonga. handles accounts, transactions, and admin management. uses sqlite.

## features

- account management
- transaction tracking
- admin panel
- sqlite database with sql backup
- backup system

## how to run

```bash
python Village.py
```

to create admin:

```bash
python create_admin.py
```
